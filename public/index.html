1Install the Claude Code CLI

Skip this if claude --version already works in your terminal. Each person sets this up on their own computer with their own Claude plan.

irm https://claude.ai/install.ps1 | iex
curl -fsSL https://claude.ai/install.sh | bash
npm install -g @anthropic-ai/claude-code

2Log in with your Claude subscription

  1. Open a terminal and run claude.
  2. Type /login, pick Claude account with subscription, and finish the sign-in in your browser.
  3. Close the CLI with /exit. Your login stays stored by the CLI itself.

No setup token or API key is needed. The normal /login is enough: the CLI remembers your login on this computer and the gateway uses it automatically. Only on a machine without a browser would you use claude setup-token and start the gateway with CLAUDE_CODE_OAUTH_TOKEN set (see the README).

This tool never asks for, reads or stores your Claude password or login token. It only starts the claude command on this computer, exactly as you would.

Security

      

        

          
What the gateway does for you

          
    
            
  • Listens on 127.0.0.1 only, so other devices cannot reach it.
    • 
            
  • Stores only a SHA-256 hash of each key; the key itself is never saved.
    • 
            
  • Per-key rate limits, expiry dates, and instant revoke.
    • 
            
  • Locks out a client after repeated wrong keys.
    • 
            
  • Dashboard needs a token that exists only in your terminal, and rejects requests from other websites.
    • 
            
  • Claude runs with all tools switched off: it cannot run commands or read your files.
    • 
            
  • Activity log records metadata only, never your prompts or replies.
    • 
          

        

        

          
Your part

          
    
            
  • Treat keys like passwords. Keep them in environment variables, never in git.
    • 
            
  • Do not expose this port to the internet or put it behind a public tunnel.
    • 
            
  • Use it for your own personal projects on this computer. Do not share or resell access; your plan's usage limits and Anthropic's terms still apply.
    • 
            
  • For a product, a team, or anything customer-facing, use a real key from the Claude Developer Platform instead.
